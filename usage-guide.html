もふもふカルテ 使い方ガイド

はじめての方が、基本の記録から必要に応じて使う機能まで順番に確認できるガイドです。スマートフォンでの利用を想定しています。

本アプリは健康情報を整理するためのもので、診断を行うものではありません。気になる症状や急な変化がある場合は、記録結果だけで判断せず獣医師へ相談してください。

1. もふもふカルテでできること 基本機能

もふもふカルテは、体重、食欲、飲水、排泄、症状、お薬などを日々記録し、変化を振り返るための健康管理ツールです。記録した内容はグラフやPDFレポートにまとめ、受診時に獣医師へ共有できます。画面は「本日の記録」「グラフ」「メニュー」の3つで構成されています。

全体の流れ

  1. Googleアカウントでログインする。
  2. 最初のペット（記録）を登録する。
  3. 画面下部の記録アイコンから、その日のごはん・排泄・体重などを記録する。
  4. 「グラフ」や「本日の記録」で変化を振り返る。
  5. 必要に応じて受診用レポートを作成する。
2. ログインして、すぐ開けるようにする 基本機能

Googleアカウントでログインして利用します。スマートフォンのホーム画面に追加しておくと、通常のアプリのようにすぐ開けます。

手順

  1. SafariまたはChromeでもふもふカルテを開く。
  2. 「Google で続ける」を押し、利用するGoogleアカウントでログインする。
  3. ログイン後、画面上部に表示される「ホーム画面に追加すると…」の案内で「追加方法を見る →」を押す。
  4. 案内を閉じた後や表示されない場合は、下の「iPhoneでホーム画面に追加する方法」を開く。
  5. 画像の手順に従い、ホーム画面へ追加する。
  6. 次回からホーム画面のアイコンを押して開く。

ホーム画面への追加の詳しい手順（画像つき8段階）は iPhoneでホーム画面に追加する方法 を参照してください。

ヒント
  • LINEやInstagram等のアプリ内ブラウザではGoogleログインできない場合があります。その場合はSafariまたはChromeで開き直してください。
  • 案内バナーは一度閉じると再表示されません。追加方法は上のリンクからいつでも確認できます。
3. ペットを登録する 基本機能

最初に、健康記録をつける対象の基本情報を登録します。複数登録している場合は、トップの「記録を切り替える」で表示する記録を切り替えられます。

手順

  1. 「＋最初のペットを登録する」を押す（登録済みの場合はメニューの「新しい記録を登録する」）。
  2. 名前を入力する。
  3. 種類を「犬」「猫」「その他」から選ぶ。
  4. 必要に応じて品種、性別、名前の敬称、誕生日を入力する。
  5. 「登録する」を押す。
  6. 複数登録している場合は、トップの「記録を切り替える」で表示する記録を選ぶ。
重要
  • 名前は必須です。品種・性別・名前の敬称・誕生日は任意です。
  • メニューの「選択中の記録を削除する」で記録を削除すると、その記録の日々の記録、写真、お薬、予防、受診歴もすべて削除され、元に戻せません。
4. 毎日の様子を記録する 基本機能

ごはん、飲水、おやつ、排泄、お散歩、体重、体温、症状、くすりなどを、画面下部に固定表示された記録アイコンから1件ずつ記録します。すべてを記録する必要はなく、その日に気づいた項目だけで構いません。

手順

  1. トップの「本日の記録」を開く。
  2. 画面下部の記録アイコン（ごはん・飲水・おやつ・おしっこ・うんち・お散歩・体重 など）から、記録したい項目を押す。
  3. 日付と時刻を確認する。
  4. 量やメモなど、必要な内容を入力する。
  5. 「保存する」を押す。
  6. 保存した記録は、その日のタイムラインに時刻順で並ぶ。
ヒント
  • 日付は見出し横の「‹」「›」で移動でき、過去の日付もさかのぼって記録できます。
  • 便は「うんち」の記録でスコア（1〜7）を選べます。

ごはん候補を設定する

よく使うごはんを候補として登録しておくと、記録時にワンタップで選べます。

  1. メニューの「ごはんの登録」を開く。
  2. 「＋追加」を押し、順に表示される入力欄に名前、内容（任意）、目安時刻（任意）を入力する。
  3. 登録した候補が一覧に表示される。
  4. 記録時は「ごはん」を押し、「ごはん（複数選択可）」から候補にチェックを入れて保存する。
5. 記録を見返す・修正する 基本機能

保存した記録は「本日の記録」のタイムラインに並びます。各記録を開くと詳細を確認でき、その場で修正・削除できます。

手順

  1. 「本日の記録」で日付を選ぶ。
  2. 見返したい記録を押して詳細を開く。
  3. 内容を直す場合は「編集」を押し、修正後に「保存する」を押す。
  4. 不要な記録は「削除」を押す。
  5. 確認を終えたら「閉じる」を押す。
重要
  • 「削除」は取り消せません。入力内容を直す場合は「編集」を使ってください。
6. お薬と投薬状況を管理する 基本機能

処方されたお薬の名前、用量、1日の回数、期間などを登録できます。登録すると「本日の記録」に投薬予定として表示され、飲ませたら予定の行を押して投薬済みにできます。

手順

  1. メニューの「くすりの登録」を開く。
  2. 「＋お薬を登録」を押す。
  3. 分かる範囲で薬の名前、用途、用量を入力する。
  4. 1日の回数と開始日を設定する（継続中なら終了日は空欄）。
  5. 必要に応じて処方元、投薬予定の時刻、薬袋・お薬手帳の写真、メモを追加する。
  6. 「保存する」を押す。
  7. 「本日の記録」に表示される投薬予定の行を押し、「保存する」で投薬済みにする。
  8. 服用を一時的に止めるときは、お薬手帳の「休薬にする」を押す。
ヒント
  • 薬品名や用量が分からない場合は空欄でも登録できます。診察時に確認できたら編集して追記してください。
  • 薬袋や診療明細の写真を残すと、次回受診時の確認に役立ちます。
治療サポートプラン（月額480円）
  • 「投薬予定の時刻」は誰でも設定でき、「本日の記録」に予定として表示されます（通知は届きません）。決まった時刻に通知を受け取る「投薬リマインダー通知」は治療サポートプランの機能です。
7. 予防と受診の記録を残す 基本機能

ワクチン、狂犬病予防、フィラリア・ノミダニ予防の実施日や次回予定日を記録できます。動物病院を受診した際の相談内容、診断名、治療内容も残せます。

手順

  1. 予防の記録はメニューの「予防」を開く。
  2. 「＋記録を追加」を押し、種類、実施日、次回予定、病院などを入力して保存する。
  3. 受診の記録はメニューの「受診歴」を開く。
  4. 「＋受診記録を追加」を押す。
  5. 受診日、病院名、相談内容、診断名・疾患名、治療内容、次回受診予定などを入力して保存する。
ヒント
  • 分からない項目は空欄でもかまいません。診断名は後から編集して追記できます。
  • 次回予定日を入力しておくと、次の予防や受診の管理に役立ちます。
  • 狂犬病は犬を登録した場合だけ選択肢に表示されます。
8. 記録の変化をグラフで見る 基本機能 一部 治療サポートプラン

記録がたまると、変化をグラフで確認できます。体重の推移と症状の出現回数は基本機能です。体温・食欲・お散歩の推移、日々の状態、症状タイムライン、60日／90日や指定期間の表示は治療サポートプランで利用できます。

手順

  1. トップの「グラフ」を開く。
  2. 上部のタブ（体重・体温・食欲・お散歩・日々の状態・症状）から見たいグラフを選ぶ。
  3. 右上の期間（直近7日／直近30日 ほか）を選ぶ。
  4. 体重の推移や症状の出現回数を確認する。
  5. 個別の記録は「本日の記録」で確認する。
重要
  • グラフは入力された記録を整理するもので、診断や異常判定を行うものではありません。
  • 記録日が少ない期間は変化を十分に確認できないことがあります。
9. 記録を獣医師に共有する 無料枠 月1回 追加購入

指定期間の記録を、診察時に見せやすいレポートとして表示・印刷・PDF保存できます。

手順

  1. メニューの「レポート出力」を開く。
  2. レポートに含める開始日と終了日を選ぶ。
  3. 「レポートを印刷 / PDF保存」を押す。
  4. 印刷画面から印刷、または共有・PDF保存を選ぶ。
  5. 診察時にスマートフォンで表示するか、PDFを共有する。

出力されるレポートの例は サンプルPDF を参照してください。iPhoneでのPDF保存の詳しい操作は iPhoneでレポートをPDF保存する方法 を参照してください。

重要
  • 1回の出力範囲は最大31日間です。それより長い期間は複数回に分けてください。
  • 無料枠は月1回です。追加出力は買い切りの追加パックを利用できます。
  • 毎月1日に無料回数が復活します。無料回数は1以上には増えません。
10. 家族共有と投薬リマインダーを使う 家族共有 追加席 リマインダー 治療サポートプラン

必要に応じて、家族との記録共有や投薬リマインダー通知を利用できます。記録への写真添付、拡張グラフ、「今週のようす」なども治療サポートプランに含まれます。

家族共有の手順

  1. 共有する側が、メニューの「家族共有」を開く。
  2. 「招待するひと：招待コードの発行」にある「発行」を押し、表示された16文字の招待コードをコピーして相手へ伝える。
  3. 参加する側もGoogleアカウントでログインし、メニューの「家族共有」を開く。
  4. 「招待されたひと：招待コードの入力」に受け取ったコードを入力して「参加する」を押す。
  5. 「家族共有に参加しています」と表示され、共有された記録を確認できることを確かめる。

招待コードは7日間有効で、1人が参加すると使用済みになります。新しいコードを再発行すると、以前の未使用コードも使えなくなります。

投薬リマインダーの手順

  1. メニューの「くすりの登録」を開き、「投薬リマインダー通知を有効にする」を押して端末の通知を許可する。
  2. お薬を登録または編集する。
  3. 「通知の時刻（治療サポートプラン）」の「＋追加」を押す。
  4. 通知する時刻を選び、時刻が追加されたことを確認する。
  5. 「保存する」を押す。
料金
  • 家族共有の追加メンバー枠は1人につき月額200円です。招待相手にはGoogleアカウントが必要です。
  • 投薬リマインダー通知、記録への写真添付、拡張グラフ、「今週のようす」などは月額480円の治療サポートプランに含まれます。
ヒント
  • 使用済みまたは期限切れの招待コードでは参加できません。必要な場合は、共有する側で新しいコードを発行してください。
  • 「投薬予定の時刻」だけなら治療サポートプランがなくても設定できます（通知は届きません）。
  • 通知は端末・OS・ブラウザの設定にも左右されます。
